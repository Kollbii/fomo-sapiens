## 2. Storage (`src/storage/`) — Phase 2 `[IMPLEMENTED]`
- **`src/storage/schema.py`:** `OptionContractRow` (field order = CSV column order, 27 columns), `COLUMNS`, `OPTION_CHAIN_POLARS_SCHEMA` (`pl.Schema`), `SpotSource = Literal["LAST", "MID", "CLOSE"]`, `SnapshotMeta` (index entry including `requested_strike_step`, optional exchange discovery fields `exchange_validated_strike_count`, `available_strike_steps`, `available_range_pcts`, `exchange_native_verified`, and optional quality fields `spot_source`, `quoted_contract_count`, `quote_coverage`, `prior_close_only_count`), and `infer_chain_step_and_range(df)` (infers effective canonical strike spacing and moneyness span directly from a chain `DataFrame`). The row model also sanitizes sentinels (prices `<= 0`/NaN/`>= 1e9` → null; counts `< 0`/NaN/`>= 2147483647` → null; `iv <= 0` or `> 10`, `abs(delta) > 1.001`, `gamma < 0` → null), derives `mid` and `mark_price` (`mid` → `last` → `close`), and requires `snapshot_id` prefix == `underlying`.
- **`src/storage/csv_repository.py`:** `CSVRepository(storage, root)`; `ensure_layout()` (idempotently creates `snapshots/`, `latest/`, and the metadata directory; called by the FastAPI lifespan so no external `mkdir` step is needed); `make_snapshot_id(ticker, ts)`; `save_snapshot(..., spot_source=...)` (refuses to overwrite an existing snapshot id, raising `StorageSchemaError`, and populates quote quality metrics via `measure_quote_quality`), `load_latest` (falls back to the newest valid archive if the cache is missing/corrupt), `load_snapshot`, `list_snapshots` (newest first), `load_index` / `rebuild_index` (self-healing with `infer_missing=True`, computing quote quality and preserving prior `spot_source`; corrupt or stray CSVs are skipped with a warning), and optional `schema: pl.Schema | None` enforcement in `validate_frame()`. Readers raise `StorageSchemaError` on header/dtype/null violations and `SnapshotNotFoundError` when nothing exists.
- **Index notes:** `file_path` / `latest_file` are root-relative POSIX paths. After `rebuild_index()`, `strike_step` and `range_pct` are inferred from CSV strikes via `infer_chain_step_and_range()` while `requested_strike_step` is `null` (since request metadata lives only in `snapshot_index.json`).
- **`src/storage/quality.py` (`MIN_QUOTE_COVERAGE = 0.90`, `USABLE_SPOT_SOURCES = {"LAST", "MID"}`, `USABLE_MARKET_DATA_TYPES = {1, 3}`):** `QuoteQuality`, `measure_quote_quality`, `SnapshotQualityVerdict`, `evaluate_snapshot`, `is_usable_snapshot` — separates live-session/usable chain snapshots from off-hours or sparse snapshots without mutating archives.
- **`src/storage/paper_trade_store.py` (`PaperTradeStore`, `PaperTrade`, `PaperTradeLeg` [1..8 legs], `PaperQuoteRecord`, `PaperTradeStatus = Literal["ACTIVE", "EXPIRED", "STOPPED"]`):** Thread-safe (`threading.RLock`) persistence for `data/metadata/paper_trades.json` (atomic `.tmp` + `os.replace()`), append-only `data/metadata/paper_quotes.jsonl` (`os.fsync()`), and immutable `data/tracked/{TICKER}/{TICKER}_{YYYYMMDD_HHMMSS}.csv` in 27-col `OPTION_CHAIN_POLARS_SCHEMA`.
- **`src/storage/backtest_store.py` (`select_daily_bar_snapshots`, `load_tracked_quotes_by_date`, `load_daily_chain_bars`, `DailyBarSelection`, `TrackedQuoteSlice`, `DailyChainBar`, `NO_USABLE_DAILY_SNAPSHOT`):** Pre-filters archive filenames in `O(window)` by `[start_date, end_date]` ET dates before opening index/CSVs, selects one canonical snapshot per trading day (latest usable else latest tagged `NO_USABLE_DAILY_SNAPSHOT`), and loads matching ET-date `data/tracked/` leg CSVs.
- **`src/storage/ledger_schema.py` & `src/storage/ledger_repository.py` (`LedgerRepository`, `LedgerExecutionRow`, `LedgerPositionRow`, `LedgerSyncState`):** Define the 23-column `executions.csv` (`LEDGER_EXECUTION_COLUMNS`, `LEDGER_EXECUTION_POLARS_SCHEMA`, `LEDGER_EXECUTION_NON_NULLABLE`) and 15-column `open_positions.csv` (`LEDGER_POSITION_COLUMNS`, `LEDGER_POSITION_POLARS_SCHEMA`, `LEDGER_POSITION_NON_NULLABLE`) contracts plus `FLEX_SOURCES`. Helpers (`sanitize_signed_float`, `sanitize_optional_conid`, `normalize_underlying`, `normalize_expiry_yyyymmdd`, `normalize_right_optional`, `normalize_utc_timestamp`, `compute_signed_proceeds`, `synthesize_exec_id`) enforce positive `abs(commission)` cost semantics, UTC ISO-8601 timestamps, signed ex-fee proceeds, and deterministic `sha256:{24hex}` exec IDs when missing. `LedgerRepository.ensure_layout()` creates `data/ledger/` and `imports/`; `upsert_executions()` upgrades matching provisional `GATEWAY_LIVE` rows via `_matches_secondary()` / `_exec_id_suffix_match()` / `_merge_execution_metadata()` in favor of authoritative `FLEX_*` records and self-heals synthetic `sha256:` vs broker-ID lifecycle duplicates (`EXPIRED`, `ASSIGNED`, `EXERCISED`) via `_lifecycle_key()` + `_merge_execution_metadata()`, `replace_positions()` swaps `open_positions.csv` atomically via `.tmp` + `os.replace()`, and `load_sync_state()` / `save_sync_state()` manage `sync_state.json`.

## 4. Analytics (`src/analytics/`) — Phase 4 `[IMPLEMENTED]`
- **`src/analytics/bsm_fallback.py` (`BSMFallbackEngine`, `enrich_missing_greeks`, `greeks_for_quotes` -> `QuoteGreeks`):** Vectorized 25-iteration hybrid Newton-Raphson + Bisection IV solver on `[0.01, 5.00]` ($T = \max(\text{dte}, 0.5) / 365.0$, guarding `np.isfinite(t_years) & (t_years > 0.0)` in `solve_implied_volatility`) and analytical BSM Greeks (`delta`, `gamma`, daily `theta`, `vega` per 1% IV), preserving native `"IBKR_MODEL"` rows and leaving unsolvable rows `"NONE"`.
- **`src/analytics/walls.py` (`WallsAnalyzer`, `compute_walls`):** Returns `ChainWallsReport` (`WallLevel`, `DTEWallSummary`, `by_dte`) ranking aggregate and per-DTE Put/Call walls by `OPEN_INTEREST` (tie-breaking on `volume`) with automatic fallback to `VOLUME` when total Open Interest is `0`.
