## 2. Storage (`src/storage/`) — Phase 2 `[IMPLEMENTED]`
- **`src/storage/schema.py`:** `OptionContractRow` (field order = CSV column order, 27 columns), `COLUMNS`, `OPTION_CHAIN_POLARS_SCHEMA` (`pl.Schema`), `SnapshotMeta` (index entry including `requested_strike_step` plus optional exchange discovery fields `exchange_validated_strike_count`, `available_strike_steps`, `available_range_pcts`, `exchange_native_verified`), and `infer_chain_step_and_range(df)` (infers effective canonical strike spacing and moneyness span directly from a chain `DataFrame`). The row model also sanitizes sentinels (prices `<= 0`/NaN/`>= 1e9` → null; counts `< 0`/NaN/`>= 2147483647` → null; `iv <= 0` or `> 10`, `abs(delta) > 1.001`, `gamma < 0` → null), derives `mid` and `mark_price` (`mid` → `last` → `close`), and requires `snapshot_id` prefix == `underlying`.
- **`src/storage/csv_repository.py`:** `CSVRepository(storage, root)`; `ensure_layout()` (idempotently creates `snapshots/`, `latest/`, and the metadata directory; called by the FastAPI lifespan so no external `mkdir` step is needed); `make_snapshot_id(ticker, ts)`; `save_snapshot` (refuses to overwrite an existing snapshot id, raising `StorageSchemaError`), `load_latest` (falls back to the newest valid archive if the cache is missing/corrupt), `load_snapshot`, `list_snapshots` (newest first), `load_index` / `rebuild_index` (self-healing with `infer_missing=True`; corrupt or stray CSVs are skipped with a warning). Readers raise `StorageSchemaError` on header/dtype/null violations and `SnapshotNotFoundError` when nothing exists.
- **Index notes:** `file_path` / `latest_file` are root-relative POSIX paths. After `rebuild_index()`, `strike_step` and `range_pct` are inferred from CSV strikes via `infer_chain_step_and_range()` while `requested_strike_step` is `null` (since request metadata lives only in `snapshot_index.json`).
- **`src/storage/ledger_schema.py` & `src/storage/ledger_repository.py` (`LedgerRepository`, `LedgerExecutionRow`, `LedgerPositionRow`, `LedgerSyncState`):** Define the 23-column `executions.csv` (`LEDGER_EXECUTION_COLUMNS`, `LEDGER_EXECUTION_POLARS_SCHEMA`, `LEDGER_EXECUTION_NON_NULLABLE`) and 15-column `open_positions.csv` (`LEDGER_POSITION_COLUMNS`, `LEDGER_POSITION_POLARS_SCHEMA`, `LEDGER_POSITION_NON_NULLABLE`) contracts plus `FLEX_SOURCES`. Helpers (`sanitize_signed_float`, `sanitize_optional_conid`, `normalize_underlying`, `normalize_expiry_yyyymmdd`, `normalize_right_optional`, `normalize_utc_timestamp`, `compute_signed_proceeds`, `synthesize_exec_id`) enforce positive `abs(commission)` cost semantics, UTC ISO-8601 timestamps, signed ex-fee proceeds, and deterministic `sha256:{24hex}` exec IDs when missing. `LedgerRepository.ensure_layout()` creates `data/ledger/` and `imports/`; `upsert_executions()` upgrades matching provisional `GATEWAY_LIVE` rows via `_matches_secondary()` / `_exec_id_suffix_match()` / `_merge_execution_metadata()` in favor of authoritative `FLEX_*` records and self-heals synthetic `sha256:` vs broker-ID lifecycle duplicates (`EXPIRED`, `ASSIGNED`, `EXERCISED`) via `_lifecycle_key()` + `_merge_execution_metadata()`, `replace_positions()` swaps `open_positions.csv` atomically via `.tmp` + `os.replace()`, and `load_sync_state()` / `save_sync_state()` manage `sync_state.json`.

## 3. Broker (`src/broker/`) — Phase 3 `[IMPLEMENTED]`

- **`src/broker/contracts.py` (`ContractDiscoveryService`, `ExpirationSpec`):** Qualifies `Stock(symbol, "SMART", "USD")`, resolves reference spot (`last` -> `mid` -> `close`, cascading Type 3 -> 4 when needed), inspects all `SMART` chains (`fetch_chains` / `select_smart_chains`) to match each weekly expiration inside `30 <= dte <= 120` (`match_expirations`, preferring Friday) to its exchange descriptor (`select_chain_for_expiration`), pre-fetches exact per-expiration `OPT` contracts (`_prefetch_exact_contracts_by_exp` using bounded `asyncio.Semaphore(EXACT_PREFETCH_MAX_CONCURRENCY = 3)` concurrency when inside a running event loop with deterministic sequential fallback outside, calling `reqContractDetailsAsync` with `strike=0.0, right=""`, cooldown pacing, timeout guard that preserves fallback to `reqSecDefOptParams` on `TimeoutError` while translating socket drops into `GatewayConnectionError`, and 15-min TTL cache), intersects candidate strikes strictly against each expiration's verified strikes (`select_strikes`) while adapting non-standard steps via `detect_native_strike_step`, computes `choose_auto_strike_step` when `strike_step=None`, derives `detect_available_strike_steps` / `detect_available_range_pcts`, auto-widens along canonical steps if total contracts would exceed `400`, and records per-expiration `ExpirationSpec`s (with `qualified_contracts` and `exact_strikes_verified`) plus `exchange_validated_strike_count` and `exchange_native_verified` notices on `ChainPlan`.

## 4. Analytics (`src/analytics/`) — Phase 4 `[IMPLEMENTED]`
- **`src/analytics/bsm_fallback.py` (`BSMFallbackEngine`, `enrich_missing_greeks`, `greeks_for_quotes` -> `QuoteGreeks`):** Vectorized 25-iteration hybrid Newton-Raphson + Bisection IV solver on `[0.01, 5.00]` ($T = \max(\text{dte}, 0.5) / 365.0$) and analytical BSM Greeks (`delta`, `gamma`, daily `theta`, `vega` per 1% IV), preserving native `"IBKR_MODEL"` rows and leaving unsolvable rows `"NONE"`.
- **`src/analytics/walls.py` (`WallsAnalyzer`, `compute_walls`):** Returns `ChainWallsReport` (`WallLevel`, `DTEWallSummary`, `by_dte`) ranking aggregate and per-DTE Put/Call walls by `OPEN_INTEREST` (tie-breaking on `volume`) with automatic fallback to `VOLUME` when total Open Interest is `0`.
- **`src/analytics/anomalies.py` (`AnomalyScanner`, `scan_anomalies`):** Returns `AnomaliesReport` (`ContractAnomaly`) flagging `volume > open_interest` (`vol_oi_ratio`) and intra-`(expiry, right)` Volume Z-score outliers (`volume_zscore >= zscore_threshold`), sorted by `(is_vol_gt_oi desc, vol_oi_ratio desc nulls last, volume_zscore desc)`.
- **`src/analytics/term_greeks.py` (`MultiDTEStructureAnalyzer`, `build_multi_dte_profiles`):** Returns `MultiDTEProfilesReport` (`DTEProfile`, `StrikeProfilePoint`, `expiries`) aligning Calls and Puts by strike across weekly `[30, 120]` expirations, computing per-expiry `atm_strike` and `atm_iv`, and honoring configured `default_market_data_type` when frames are empty.
- **`src/analytics/strategies/` (`models.py` request/response models, `chain.py` `PreparedRow`/`prepare_rows`, `builders.py` `suggest_strategy_legs_from_walls`, `engine.py` `evaluate_strategy`; public API re-exported from `__init__.py`):** Pure Polars + NumPy/BSM strategy engine supporting `BULL_PUT_SPREAD`, `BULL_CALL_SPREAD`, `DIAGONAL_SPREAD`, `IRON_CONDOR`, and user-picked `CUSTOM` multi-leg definitions over cached option chains. Computes `Mid`/`Natural`/Slippage/Limit Ladder execution metrics, exact grid risk bounds (`max_profit`, `max_loss`, `max_loss_unbounded`, `return_on_risk_pct`, `breakevens`), log-normal `prob_of_profit_pct`, `±1σ` expected move, net position Greeks, and interactive `Today (T+0)` / `Midpoint` / `At Expiration` / `Simulated (T+n ΔIV)` BSM P&L curves.
- **`src/analytics/ledger/` (`models.py`, `classifier.py`, `rolls.py`, `engine.py`; public API re-exported from `__init__.py`):** Pure Trade Ledger & roll-chain analytics (`LedgerWindow`, `LedgerGroupBy`, `LedgerView`, 17 `LedgerStrategyType` values, `RollAction`, `CampaignStatus`, `MarkSource`, `RollStep`, `LedgerCampaignRow`, `LedgerBreakdownRow`, `LedgerOpenPositionView`, `LedgerExecutionView`, `LedgerChartPoint`, `LedgerKPIs`, `LedgerAnalyticsReport`). `classifier.py` (`compute_initial_stk_shares`, `cluster_option_episodes`, `_episode_lifecycle_kind`, `aggregate_legs`, `classify_option_legs`) groups by `ib_order_id` plus `<= 2.0s` unlinked gap, merges adjacent `<= 2.0s` episodes sharing `_episode_lifecycle_kind` (`TRADE` vs lifecycle events) so multi-leg fills with distinct `ib_order_id`s cluster together, and checks uncovered stock shares before choosing `COVERED_CALL` vs `NAKED_CALL`; `rolls.py` (`build_underlying_ledger`, `compute_roll_label`, `resolve_campaign_status`, `_invert_legs_for_classification`, `_link_stock_realizations_to_assignments`) sorts same-second `opt_execs` opens before closes, runs FIFO lot matching (classifying pre-window orphan closes via implied opening orientation without fabricating lots), and stitches simultaneous + `roll_max_gap_hours` (`24.0h`) sequential rolls; `engine.py` (`build_ledger_report`, `compute_window_start`) separates `realized` ex-fee P&L + sidecar `fees` from `open_mtm` (`LIVE_GATEWAY` -> `FLEX_MARK` -> `NONE`) and `include_stock_gain`.
