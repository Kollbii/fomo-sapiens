## 2. Backend Rules (`src/web/api.py`, `src/web/backtest_api.py`, `src/web/errors.py`, `src/main.py`)
- Routes stay thin: parse HTTP input, call one service method (`AnalyzerService` / `PaperTradeService` / `backtest` — running `TickerValidator`), return its model. Domain errors map to JSON in `src/web/errors.py`: `409` concurrency/paper-trade guards (`REFRESH_BUSY`, `DUPLICATE_PAPER_TRADE`, `PAPER_TRADE_CAP`, `PAPER_TRADE_STATE`, `WATCHLIST_FULL`), `422` ticker/request/config/backtest (`INVALID_TICKER`, `INVALID_REQUEST`, `BACKTEST_VALIDATION_ERROR`, `CONFIGURATION_ERROR`), `404` missing snapshot, `503` Gateway offline (configured `{host}:{port}`) or `STORAGE_UNAVAILABLE`, `502` fetch/spot/Flex (`FLEX_SERVICE_ERROR`), `429` pacing, `403` security. Never leak tracebacks to the browser.
- Routes: `GET /api/status`, `GET /api/snapshots/{ticker}`, `GET /api/chain/{ticker}`, `POST /api/refresh`, `POST /api/refresh/batch`, `GET /api/refresh/batch/current`, `GET /api/refresh/batch/{batch_id}`, `POST /api/refresh/batch/{batch_id}/cancel`, `GET /api/watchlist`, `POST /api/watchlist/tickers`, `DELETE /api/watchlist/tickers/{ticker}`, `GET /api/csv/{ticker}`, `POST /api/strategy/suggest`, `POST /api/strategy/evaluate`, `POST /api/corridor/quotes`, `POST /api/corridor/stop`, `GET /api/corridor/stream/{ticker}`, `GET /api/ledger`, `POST /api/ledger/sync`, `POST /api/ledger/import`, `POST /api/ledger/mtm`, `GET /api/backtest/entries/{ticker}`, `POST /api/backtest/run`, `POST /api/screener/run`, `GET /api/screener/stream`, `POST /api/screener/stream/reallocate`, `POST /api/screener/stop`, `GET /api/backtest/paper-trades`, `POST /api/backtest/paper-trades`, `POST /api/backtest/paper-trades/{trade_id}/stop`, `POST /api/backtest/paper-trades/sync-ledger`. ## 3. Frontend Rules & Golden UI/UX Checklist
- **Themes & Tokens:** `data-theme="print"` (NYT newsprint `#FBF9F5`, black serif, `3px double` rules) and `data-theme="terminal"` (`#0A0D12`, ivory serif, crisp Cyan `#38BDF8` `--accent-primary` CTA, emerald/red calls/puts, Amber `#F59E0B` `--accent-warn` strictly for warnings/delayed). Persist in `localStorage`; re-skin every Plotly chart on toggle without refetching.
- **Colors & Design System Hygiene:** Colors, shadows, and overlays ONLY via CSS custom properties defined identically for both themes in `tokens.css` (row styles live in `css/*.css`). Zero hardcoded hex, `rgb()`, `rgba()`, or `hsl()` values outside `tokens.css`.
- **Canonical Components:** Card headers MUST use `<header class="panel-header">` + `.panel-title-stack` + `.panel-controls` (no dead `.panel-head` classes); buttons use `.btn` / `.btn-primary` / `.btn-sm` / `.btn-xs` (plus `.wl-btn-small` in watchlist footer); badges use defined `.badge--*` variants; panel switches use `.panel-toggle-pill` exclusively (`9` panels).
- **Typography Role Discipline & Accessibility:** `--font-editorial` (`Newsreader`) for headlines/titles; `--font-sans` (`Inter`, `>= 11px` labels, `12px–13px` prose) for buttons, field/KPI labels, notices, warnings, rationales, and empty states; `--font-mono` (`JetBrains Mono`) + `font-variant-numeric: tabular-nums` strictly for prices, strikes, Greeks, timestamps, tickers, inputs, and tables. No sub-`10px` CSS labels outside `.wl-logo__fallback`. Clear WCAG 2.1 AA (`>= 4.5:1`) contrast and `:focus-visible` `2px solid var(--accent-focus)` outlines on every interactive control.
- **Progressive Disclosure & Plain Language:** Favor Overview -> Filter -> Details; explain domain flags/errors in plain English with technical tracebacks tucked in `<details>` or tooltips; make Network (IBKR/Flex) vs. Local-Cache actions unmistakable.
- Keep `#editorial-banner-slot` structural.
- Network to IBKR/Flex only on explicit user click/toggle (Refresh, Corridor, the opt-in Best Option `Live` checkbox, `[Sync Flex / Gateway]`, `[Refresh Open MTM]`). Strategy Lab auto-build, Backtest simulation / Paper Trade registration, stop & Trade Ledger sync (`POST /api/backtest/paper-trades/sync-ledger`, plus Replay triggers from Trade Ledger), and Trade Ledger filter/window/view/group queries (`GET /api/ledger`) stay cache/local-only; active paper-trade legs are quoted strictly as post-refresh follow-up inside manual Refresh (no background daemon); keep `Realized & Credits` strictly separated from `Open & Unrealized MTM` (with `ibkr_ledger_prefs_v1`).
- Plotly: `Plotly.react` for updates; `if (!el.data) el.innerHTML = ""`; `Plotly.purge(el)` before placeholders; no HTML entities (`&bull;`, `&mdash;`) in JS strings — use `\u2022` / `\u2014`.
- After any CSS/JS edit, bump the `?v=` cache-busters in `base.html` (stylesheet loop) and `index.html` (`dashboard/main.js`).
- Ticker input: `maxlength="5"`, `pattern="^[A-Za-z]{1,5}$"`, auto-uppercase, inline `422` banner.
